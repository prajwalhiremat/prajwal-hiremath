# Beginner LeetCode Practice — 50 Java Solutions

This folder contains 50 beginner-focused LeetCode problems covering numbers, conditions, loops, strings, 1D arrays, and 2D arrays.

## How to run a solution

Open a problem folder in VS Code or a terminal. Each Java file has its own public class and a `main` method for local testing.

```bash
javac TwoSum.java
java TwoSum
```

Enter the input values requested by the problem. Input formats are simple: array programs usually read the array length followed by its elements; matrix programs read rows, columns, and then matrix values; string programs read one or two strings.

## How to submit on LeetCode

Open the linked problem, select **Java**, and paste the corresponding solution method into LeetCode's supplied `class Solution`. The repository files also contain a `main` method so a teacher can compile and run them locally. The algorithm method uses the problem's LeetCode method name and parameters.
